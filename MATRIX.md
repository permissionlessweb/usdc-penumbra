# Todo matrix

Begin walks the steps. A step turns acknowledged only after the balance it should change has changed. A failed step stops the queue. Later steps do not run.

Three labels:

- **Sound.** The page refuses a wrong action. No invented balance, no invented address, no spend key on the page, no hop key issued.
- **Usable.** A person can see the running step, and can tell a missing wallet from a missing balance.
- **Complete.** The step has run once against real wallets. Record the run in the pull request. Do not paste a production transaction hash into the page.

No row is Complete. The author signed Begin from USDC on Osmosis through the Injective deposit. The Penumbra row stayed at 0 USDC. The arrived asset is USDC.inj on transfer channel 18, and the page sums the symbol USDC. The walk is also covered by stand-in tests.

What is still open:

- The mixnet is closed. Bank balances, account numbers, and transaction results are read from the public LCD. Penumbra balances are read from Zafu. Cosmos transactions are broadcast by Keplr. `query` and `broadcast` still throw. The page does not fetch a chain RPC.
- The Penumbra read does not separate USDC.noble from USDC.inj. A deposit that lands as USDC.inj is not shown.
- A Penumbra withdrawal uses the return channel Zafu names. If that balance is not named as USDC on a transfer channel, the leave stops before it is signed. No shielded balance has left.
- Circle's burn is quoted when that step runs. A route that swaps is refused. An Osmosis balance returns in one transfer whose memo burns it on arrival, so the Noble account does not sign and does not pay that fee. A balance that is already on Noble still burns in its own transaction, and that transaction leaves the fee in the account. The page waits for the Injective balance. If that balance does not rise, the step fails and shows the hash of the transaction that carried the burn.
- Inbound USDC uses one diversified address. Slices do not fan out.
- The fee swap is quoted before any send. Only the INJ the swap gained is bridged. A refused quote sends nothing when the selected Osmosis balance covers the quote. A Noble top-up moves only the quoted USDC, and a refused swap after that top-up can leave that USDC on Osmosis. A Penumbra exit still leaves before the fee swap. USDC that is already only on Injective cannot buy the fee.
