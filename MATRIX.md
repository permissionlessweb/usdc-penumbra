# Todo matrix

Begin walks the steps. A step turns acknowledged only after the balance it should change has changed. A failed step stops the queue. Later steps do not run.

Three labels:

- **Sound.** The page refuses a wrong action. No invented balance, no invented address, no spend key on the page. A Penumbra slice holds one Injective key and drops it after that slice's deposit.
- **Usable.** A person can see the running step, and can tell a missing wallet from a missing balance.
- **Complete.** The step has run once against real wallets. Record the run in the pull request. Do not paste a production transaction hash into the page.

No row is Complete. The author signed Begin from USDC on Osmosis through the Injective deposit, and that path landed. The Penumbra row stayed at 0 USDC on that run because the check was a symbol total. The page now reads USDC.noble and USDC.inj separately. That read has not been repeated in the browser. A Penumbra slice has been planned and shown to Zafu. Zafu did not broadcast it. The walk is also covered by stand-in tests.

What is still open:

- The mixnet is closed. `query` and `broadcast` throw, and there is no direct chain RPC. The queries that do run are not on Nym. Keplr bank reads use the public LCDs (`lcd.osmosis.zone`, `noble-api.polkachu.com`, `lcd.injective.network`). The burn quote uses `api.skip.build`. The INJ quote uses `sqs.osmosis.zone`. Keplr broadcasts a Cosmos transaction inside the extension. The slice's Injective deposit is broadcast to the Injective LCD. Penumbra reads and Penumbra broadcasts go through Zafu.
- The Penumbra row names USDC.noble and USDC.inj. USDC.noble is the transfer denom ending in uusdc. USDC.inj is the transfer denom ending in the Injective USDC address. A symbol-USDC total is not the arrival check. This split has not been seen in the browser since it was added.
- A Penumbra slice signs the fee withdrawal, then signs the migration, on the return channel Zafu names for USDC.noble. The first buys the fee for a new Injective account. The second carries the burn memo to that account. That account deposits to the same Zafu address. The flow is written in docs/batch-out.md. Live attempts stopped before a packet left. The planner rejected a missing timeout height. The page then rejected a real Osmosis quote because the pools were listed from INJ back to USDC. Zafu then refused one plan that held both withdrawals, because the approval QR could not hold the bytes. The page now sets the timeout from the light client, reverses that pool list, and uses two signatures. The QR that rendered was clipped on the sides by the popup frame, so it could not be scanned. No shielded balance has left. The Osmosis contract's inj channel and the `pfm` receiver have not been sent live. The signer frame is not fixed in this repository.
- A localhost return sends Osmosis USDC.noble to the connected Noble account and forwards it to the Zafu address on the channel the light client names. A packet whose receiver was `pfm` was rejected by Noble before the forward ran. The corrected packet has not been acknowledged by a rise in Zafu USDC.noble.
- Circle's burn is quoted when that step runs. A route that swaps is refused. An Osmosis balance returns in one transfer whose memo burns it on arrival, so the Noble account does not sign and does not pay that fee. A balance that is already on Noble still burns in its own transaction, and that transaction leaves the fee in the account. The page waits for the Injective balance. If that balance does not rise, the step fails and shows the hash of the transaction that carried the burn.
- Inbound USDC uses one diversified address. Slices do not fan out.
- The fee swap is quoted before any send. Only the INJ the swap gained is bridged. A refused quote sends nothing when the selected Osmosis balance covers the quote. A Noble top-up moves only the quoted USDC, and a refused swap after that top-up can leave that USDC on Osmosis. That hop is for USDC already outside Penumbra. A Penumbra slice buys the fee for its own Injective account. USDC that is already only on Injective cannot buy the fee.
